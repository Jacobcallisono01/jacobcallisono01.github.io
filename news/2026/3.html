Jacobcallisono OS New version spot moved

The new Jacobcallisono OS versions will be placed in a different spot.

The limitations of Github Pages makes it a lot harder to actually put new versions in, so we will be putting them on Google Drive instead.

Being able to only have up to 15GB of space to put all those versions in is a lot better than being limited to only 25MB per file!

So, the new version updates will be placed on Drive instead.

You can still download the versions, but they will be on a different spot.

So, they will be availible to anyone with the link.

It's easier this way, so there will also be a new "Versions" page so you can also download historical versions (Builds of Jacobcallisono OS 0.4 and 0.3 versions).
